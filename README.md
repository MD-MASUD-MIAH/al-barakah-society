## 🌿 প্রজেক্ট পরিচিতি (Overview)
**আল-বারাকাহ সোসাইটি (Al-Barakah Society)** হলো একটি ইসলামী মূল্যবোধ ও স্বচ্ছ হিসাবভিত্তিক কমিউনিটি ম্যানেজমেন্ট প্ল্যাটফর্ম। এর মূল লক্ষ্য হলো সদস্যদের সঞ্চয় আমানতদারিতার সাথে সংরক্ষণ করা, মাসিক ও বার্ষিক খতিয়ানের নির্ভুল হিসাব রাখা এবং সদস্যদের মধ্যে রিয়েল-টাইমে নোটিশ ও মতবিনিময় নিশ্চিত করা।

## 🛠️ প্রযুক্তি স্ট্যাক (Tech Stack)

### ফ্রন্টএন্ড (Frontend)
- **React (Vite):** আধুনিক কম্পোনেন্ট আর্কিটেকচার ও দ্রুত পারফরম্যান্স
- **Tailwind CSS:** প্রিমিয়াম ইসলামিক এমারেল্ড-গোল্ড ড্যাশবোর্ড থিম
- **Lucide React:** দৃষ্টিনন্দন আধুনিক আইকন সেট
- **Axios:** এপিআই কল ও ইন্টারসেপ্টর (JWT Bearer Token হ্যান্ডলিং)
- **React Router DOM (v7):** ক্লায়েন্ট-সাইড রাউটিং ও রোল-বেসড প্রোটেক্টেড রুট
- **Socket.io-client:** রিয়েল-টাইম কমিউনিটি চ্যাট, নোটিশ ও অনলাইন উপস্থিতি
- **Canvas Confetti:** সফল জমা ও অনুমোদনে ইন্টারেক্টিভ অ্যানিমেশন

### ব্যাকএন্ড (Backend)
- **Node.js & Express.js:** স্কেলেবল RESTful API সার্ভার
- **JSON Web Tokens (JWT) & bcryptjs:** নিরাপদ অথেনটিকেশন ও পাসওয়ার্ড হ্যাশিং
- **Socket.io:** লাইভ ব্রডকাস্টিং, মেসেজিং এবং অনলাইন মেম্বার ট্র্যাকিং
- **CORS & Dotenv:** পরিবেশগত ভেরিয়েবল ও ক্রস-অরিজিন পলিসি নিয়ন্ত্রণ

### ডেটাবেস (Database)
- **MongoDB Atlas (Mongoose ODM):** ক্লাউড ডেটাবেস, ইনডেক্সিং এবং স্বয়ংক্রিয় ব্যালেন্স রিক্যালকুলেশন হুক

## 🗄️ ডেটাবেস স্কিমা ও নির্ভুল হিসাব (Data Integrity)

1. **User Schema (`users`)**:
   - `name`, `email`, `phone`, `password` (হ্যাসড), `avatar`, `role` (`'member' | 'admin'`), `status` (`'pending' | 'approved' | 'rejected' | 'suspended'`), `totalDeposited`, `timestamps`.
2. **Deposit Schema (`deposits`)**:
   - `memberId` (User ref), `amount`, `paymentMethod` (`'cash' | 'bkash' | 'nagad' | 'bank'`), `trxId`, `date`, `recordedBy` (Admin ref), `note`, `status` (`'verified'`), `timestamps`.
   - **স্বয়ংক্রিয় হিসাব সুরক্ষা:** প্রতিটি জমা তৈরি, আপডেট বা মুছে ফেলার সাথে সাথে Mongoose পোস্ট হুক ও অ্যাগ্রিগেশন পাইপলাইনের মাধ্যমে সদস্যের `user.totalDeposited` স্বয়ংক্রিয়ভাবে শতভাগ নির্ভুলভাবে আপডেট হয়।
3. **Message Schema (`messages`)**:
   - `senderId` (User ref), `senderName`, `senderRole`, `senderAvatar`, `message`, `isNotice`, `timestamps`.

## 🚀 সেটআপ ও রান করার নির্দেশিকা (Step-by-Step Setup)

### ১. ডিপেন্ডেন্সি ইনস্টলেশন (Install Dependencies)
রুট ডিরেক্টরি থেকে ক্লায়েন্ট এবং সার্ভারের প্যাকেজ ইনস্টল করুন:
```bash
# সার্ভারের ডিপেন্ডেন্সি ইনস্টল
cd server
npm install

# ক্লায়েন্টের ডিপেন্ডেন্সি ইনস্টল
cd ../client
npm install
```

---

### ২. এনভায়রনমেন্ট কনফিগারেশন (`.env`)
`server/.env` ফাইলটি ওপেন করুন অথবা `.env.example` থেকে কপি করুন:

```env
PORT=5000
MONGO_URI=mongodb+srv://<username>:<password>@cluster0.xxxx.mongodb.net/al_barakah_society?retryWrites=true&w=majority
JWT_SECRET=al_barakah_super_secret_jwt_key_2026_biswasher_bondhon
CLIENT_URL=http://localhost:5173
NODE_ENV=development
```

---

### ৩. MongoDB Atlas ক্লাউড ডেটাবেস সংযোগ নির্দেশিকা (Connecting to MongoDB Atlas)

1. [MongoDB Atlas](https://www.mongodb.com/cloud/atlas)-এ লগইন করে একটি ফ্রি ক্লাস্টার তৈরি করুন।
2. **Database Access** মেন্যু থেকে একটি নতুন ডাটাবেস ইউজার তৈরি করুন (যেমন: ইউজারনেম `albarakah_user` এবং পাসওয়ার্ড `SecurePass123`).
3. **Network Access** মেন্যু থেকে `0.0.0.0/0` (Allow Access from Anywhere) আইপি যোগ করুন।
4. ক্লাস্টারের **Connect** বাটনে ক্লিক করে **Drivers (Node.js)** অপশনটি নির্বাচন করুন।
5. প্রাপ্ত কানেকশন স্ট্রিংটি কপি করে `server/.env` ফাইলের `MONGO_URI` হিসেবে পেস্ট করুন এবং `<password>` স্থানে আপনার পাসওয়ার্ড বসান।

---

### ৪. ডেমো ডাটা সিড করুন (Database Seeding)
অ্যাডমিন অ্যাকাউন্ট, অনুমোদিত সদস্য, পেন্ডিং আবেদন, নমুনা জমা এবং নোটিশ তৈরি করতে রান করুন:
```bash
npm run seed --prefix server
```

## 📡 এপিআই রুট নির্দেশিকা (API Endpoints Reference)

### অথেনটিকেশন (`/api/auth`)
- `POST /api/auth/register` — নতুন সদস্য রেজিস্ট্রেশন (স্ট্যাটাস ডিফল্ট `pending`)
- `POST /api/auth/login` — লগইন (অনুমোদিত না হলে বাংলা নোটিশ প্রদান)
- `GET /api/auth/me` — বর্তমান লগইনকৃত ইউজারের সেশন প্রোফাইল

### আর্থিক লেজার ও জমা (`/api/deposits`)
- `GET /api/deposits/stats` — মোট জমা ফান্ড, সক্রিয় সদস্য, চলতি মাসের জমা
- `GET /api/deposits` — ফিল্টারযোগ্য সম্পূর্ণ লেজার তালিকা (সার্চ, মেম্বার, মেথড, ডেট)
- `GET /api/deposits/my-deposits` — সদস্যের ব্যক্তিগত জমার বিবরণ
- `GET /api/deposits/:id/receipt` — ডিজিটাল মানি রিসিট অবজেক্ট
- `POST /api/deposits` — নতুন জমা রেকর্ড করা *(শুধুমাত্র অ্যাডমিন)*
- `DELETE /api/deposits/:id` — জমা এন্ট্রি মোছা ও স্বয়ংক্রিয় ব্যালেন্স সমন্বয় *(অ্যাডমিন)*

### সদস্য ও অনুমোদন ব্যবস্থাপনা (`/api/users`)
- `GET /api/users/pending` — অপেক্ষমাণ রেজিস্ট্রেশন রিকোয়েস্ট তালিকা *(অ্যাডমিন)*
- `PUT /api/users/:id/approve` — সদস্যপদ অনুমোদন করা *(অ্যাডমিন)*
- `PUT /api/users/:id/reject` — আবেদন বাতিল করা *(অ্যাডমিন)*
- `DELETE /api/users/:id` — অ্যাকাউন্ট সম্পূর্ণ মুছে ফেলা *(অ্যাডমিন)*
- `PATCH /api/users/:id/manage` — রোল বা স্ট্যাটাস আপডেট করা *(অ্যাডমিন)*
- `GET /api/users/approved` — অনুমোদিত সদস্যদের তালিকা (ডিরেক্টরি ও ড্রপডাউন)
- `PUT /api/users/profile` — নিজের প্রোফাইল বা পাসওয়ার্ড পরিবর্তন

### কমিউনিটি যোগাযোগ (`/api/messages`)
- `GET /api/messages` — সর্বশেষ বার্তা ও নোটিশ তালিকা
- `POST /api/messages` — বার্তা বা অফিসিয়াল নোটিশ প্রেরণ (রিয়েল-টাইম সকেট ইমিট)
- `DELETE /api/messages/:id` — বার্তা মোছা
